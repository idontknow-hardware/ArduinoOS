## wymagania minimalne i zalecane
**minimalne**
- Arduino Uno
- czujnik IR
- pilot
- 2 ekrany LCD 16*2
**zalecane**
- Arduino Uno
- czujnik IR
- pilot
- 2 ekrany LCD 16*2
- RTC do pokazywania czasu
## instalacja
1. pobierz kod
2. otwórz go w Arduino IDE
3. kliknij "upload"
4. poczekaj aż sie zakończy
